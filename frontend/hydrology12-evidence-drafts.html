Hydrology-12 / 13 — مسودات الأدلة الميدانية واستكمالها

نموذج محلي لتوثيق مراجع الصور والمعاينات والقياسات والمستندات، ثم تنزيل مسودة JSON أو CSV على جهازك. لا يرفع ملفات أو صورًا إلى أي خادم ولا يحتفظ ببيانات بين الجلسات.

مسودات غير معتمدة. إدخال صور أو قياسات أو أسماء جهات لا يثبت صحتها، ولا يغير حالة الطريق أو خطر السيول. لا تستخدم النموذج لإصدار قرار تشغيل أو تصريح عبور.

1. استيراد التقرير الأصلي

اختر ملف Hydrology-10 الأصلي من جهازك.

2. استكمال مسودة سابقة (اختياري)

حمّل ملف Hydrology-10 الأصلي أعلاه أولًا، ثم اختر ملف JSON الذي صدّرته سابقًا من Hydrology-12. لا تستخدم ملف CSV أو XLSX لإعادة الاستيراد؛ لأنهما للعرض فقط.

حمّل التقرير الأصلي أولًا.

3. اختيار سجل المراجعة

لا توجد إدخالات.

4. تنزيل المسودة

للحفظ الدائم اضغط أحد الزرين. اختر مجلدًا خاصًا، ولا ترفع صورًا شخصية أو ملاحظات غير منشورة إلى GitHub. تنزيل CSV لا يصادق على البيانات.

للعرض في Excel افتح ملف TSV الجديد مباشرةً، ثم احفظه بصيغة XLSX. وللاستكمال داخل RainGuard احتفظ دائمًا بملف JSON أيضًا.
