RainGuard AI - Index Additions Reviewed

هذا الملف يحتوي على الكود الصحيح الذي تضيفه إلى frontend/index.html لربط صفحة Alert Command Center وتفعيل صندوق تنبيهات المطر داخل تبويب التنبيهات.

1) زر Alert Command Center داخل القائمة الجانبية

<button class="rg-nav-item" onclick="window.open('alert-command-center.html','_blank')">
    <i class="fa-solid fa-tower-broadcast"></i>
    مركز العمليات
</button>

2) زر التنبيهات داخل القائمة الجانبية

<button class="rg-nav-item" onclick="showProPanel('alertsPanel', this)">
    <i class="fa-solid fa-bell"></i>
    التنبيهات
</button>

3) قسم التنبيهات داخل index.html

<section class="rg-panel" id="alertsPanel">

    <section class="rg-card">

        <div class="rg-card-title">
            <h2>🌧️ التنبيهات النشطة</h2>

            <button onclick="enableRainNotifications()">
                تفعيل التنبيهات
            </button>
        </div>

        <div id="rainAlertLifecycleBox">
            لا توجد تنبيهات مطر نشطة حالياً.
        </div>

    </section>

</section>

4) تحديث روابط الملفات في آخر index.html

ضع روابط CSS داخل <head>، وضع script قبل نهاية </body>. لا تضع رابط CSS في آخر الصفحة إذا كان موجوداً مسبقاً في الأعلى؛ فقط غيّر رقم النسخة. 
<link rel="stylesheet" href="/style.css?v=384">

<script defer src="/app.js?v=384"></script>
